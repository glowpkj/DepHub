0.1.27 | Compact panel and fruit cleanup. The panel now opens at 600x420 (RedzLib reads the size from its own Default.UISize, so the size is actually applied instead of being declared and dropped), and it stays resizable -- drag the edges and RedzLib remembers the size. Tabs and categories now use real Unicode emoji icons (Combat, Player, Fruits, ESP, Teleport, Settings and so on) instead of Roblox image ids. The fruit tab drops the two distance sliders: fruit ESP and grab now have unlimited range, with no configurable limit, so a fruit is never ignored just because it is far -- the scan still only does the same cheap existence/validity checks. Skip list and Store keep list are now multi-select fruit dropdowns built from the game's own fruit-name list: pick fruits by name, no typing, no duplicates, remove by unchecking, and the choices drive exactly the same skip/keep the old text fields did. Under the hood, three events that never worked now do: Heartbeat (island arrival), RenderStepped (dashboard FPS) and InputBegan (open/close key) were checked with `type(x) == "table"`, but Roblox events are RBXScriptSignal, not tables, so the checks were always false and the connections never happened -- they are now pcall-guarded connects.
0.1.01 | Shared UI (every game): sections now hug their content. A section's height is the measured content of its body, and since that measurement already includes the body's own padding the old size added an extra 24px of dead space under the last control -- the empty band that showed up at the bottom of a section. Removed. Also added real VStack/HStack grouping: related controls sit side by side on one line (a toggle next to the slider that drives it, the switches of one feature together) across Volleyball 4.2, Universal, Violence District, TSB, MM2, Noob Piece, AOT:R, Blood Strike, Steal An Egg, Restaurant Tycoon 3 and Blox Fruits, so tabs are shorter and less cluttered. New shell primitives AddHStack/AddVStack, exposed as Kit.Row/Kit.Stack, with tests.
0.1.00 | Shared UI (every game) + Debug: full English pass. Every player-visible string -- tab names, section titles, toggle/slider labels, paragraphs, notifications, status reads and the Debug console vocabulary ([FAIL], module/probe details, command replies) -- is now English (was Portuguese). Docs and code comments stay in Portuguese. Also the default open/close key is now N. The Debug tab, loader notes and backend diagnostics all read in English.
0.0.99 | Violence District: reorganised into the standard categories -- Visual (ESP), World (generator repair + skill check) and Combat (parry). The single game-named tab is gone.
0.0.98 | Violence District: the tab now actually shows its controls. The shared shell's tab:CreateSection takes (title, column) and rejects any column other than Left/Right; the backend was passing a summary string in the column slot, so every section failed inside its pcall and the tab came up empty. Fixed the call (same fix applied to Blood Strike and Steal An Egg, which had the identical mistake). ESP by role (Killer/Survivor) with Highlight chams and a name/distance billboard, auto repair via the generator RepairEvent, the skill-check assist via SkillCheckResultEvent, and auto parry with the Parrying Dagger. Remotes are resolved lazily so a slow or missing remote never blocks the panel. Routed from place 93978595733734 and universe 6739698191.
