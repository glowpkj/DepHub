0.1.37 | Steal An Exu gets a Steal All button (Farming > Auto Steal). One press clears EVERY exu in the game in a single pass, from Terreiro9 down to Terreiro1, with 0.25s between each. For each exu it tries the Runtime prompt from range first (the prompt's activation distance is widened for the instant it fires, then put back), and blinks the teleport onto the Nest for a second try so it still lands on a game that re-checks distance server-side. When the pass ends you are back exactly where you pressed it (your base). The Auto Steal Exu toggle is untouched and still loops one Terreiro on its own.
0.1.36 | Steal An Exu gets its first feature: Auto Steal Exu. Pick a Terreiro in the panel (Farming > Auto Steal), flip the toggle, and it clears that Terreiro in a loop -- an instant teleport to each Nest, uses the Runtime prompt on the exu that lives there, then back to your base to store it, 0.5s between rounds. Your base is found from the Owner attribute on the pens (matched to your own UserId) instead of a fixed Pen1, so it stays right after a server change and works for whoever runs the script. No position anti-cheat in the game, so the teleport is direct rather than a tween.
