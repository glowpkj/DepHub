0.0.81 | Blox Fruits farm: two real tuning sliders (Approach distance and Attack interval) that write straight through to the farm config. A slider with a fractional range now keeps its precision instead of rounding every value to a whole number, so an interval like 0.35s is actually reachable.
0.0.80 | Blox Fruits: the sidebar now shows only the sea you are in plus the shared pages. On Sea 2 that means GENERAL and SEA 2 -- the combined SEA 1/2 and SEA 2/3 categories are gone. Features shared by more than one sea (Travel on Sea 1/2, Events and Fruits on Sea 2/3) are re-filed under the current sea, so nothing disappears; the sea categories also got their own icons.
0.0.79 | Steal An Egg (place 107778070777162): teleport ported from Blox Fruits -- a CFrame tween fly that glides the HumanoidRootPart to the target at a set fly speed, zeroing linear velocity and stripping collision during the move (noclip) while never anchoring the character. Targets are saved in game as waypoints (persisted to disk when the executor exposes file IO, otherwise kept in memory), because the map coordinates are not known ahead of time. Controls live in a fixed Teleport tab.
0.0.78 | New backend for Steal An Egg (place 107778070777162): the walk-speed feature ported from the Blox Fruits player module, and only that -- a "Speed boost" toggle and a "Walk speed" slider (16-300, default 50) driven by a RenderStepped loop that re-applies the value every frame, so the game controller cannot overwrite it. Controls live in a fixed Speed tab.
0.0.77 | New backend for Blood Strike (place 114234929420007): a character ESP that reads fighters from workspace.Characters (Models named after their owner) with a fallback to the standard Players surface, plus a team check, range, and name/distance/health/chams options. Controls live in a fixed ESP tab.
0.0.76 | Every game now gets a fixed Dashboard tab built by the loader itself, so the same home screen shows no matter which backend runs: the player greeting card (avatar, name, clock) plus the game/server card, and live performance metrics (framerate, latency, players, session). It reuses the library's own dashboard builders, so there is no game-specific code.
0.0.75 | The shared UI theme was split into ten ordered modules under src/core/ui/theme/ (data, sub-tabs, constructor, theme-apply, notifications, window, extras, public-api, controls, lifecycle); the orchestrator loads them in the original section order and each adds its methods to the one Library table, so behaviour is unchanged while the 13k-line file is now maintainable in pieces.
0.0.74 | The real UI theme is now covered by an automated test: the suite loads the actual demon-theme.luau (not the stub the backend tests use), builds a window against a Roblox double, then creates a category, tab, section and controls and destroys it, so a theme regression fails the suite instead of only showing up in-game.
