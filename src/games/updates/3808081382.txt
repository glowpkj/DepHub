0.0.73 | The Debug tab and the print/warn log hooks are now opt-in and off by default, so the hub runs clean in every game; the collector and every backend probe keep running underneath. Set env.__DEPHUB_ENABLE_DEBUG = true before loading, call __DEPHUB_DEBUG() live, or use the debug on|off console command to bring the tab back without reloading.
0.0.72 | The universal backend now builds its own UI in the shared shell (Movement, Visuals, Combate, Social, Servidor, Status) and instruments the Debug tab with its own probes, features and commands, so an unmapped game gets working controls and live diagnostics instead of an empty window.
0.0.71 | The loader now self-heals a stale bootstrap: when the remote version is newer than the cached build the executor served, it re-fetches DepHub.lua with a cache-bust token and re-executes it once, guarded against looping, so a fixed bootstrap URL never runs an old loader again.
0.0.70 | An unrecognised game now loads the universal backend automatically instead of stopping on the empty unsupported state; set env.__DEPHUB_DISABLE_UNIVERSAL to true to opt out and get the plain unsupported window back.
0.0.69 | The FPS metric now resolves through three routes in order -- FrameRate:GetValue(), FrameRate.Value, then the engine physics frame rate -- so it no longer sits at 0 on executors where FrameStats.FrameRate is exposed as a value object rather than a plain number.
0.0.68 | Module fetches now carry a per-session cache-bust token, so an executor's HttpGet cache can never serve a stale older revision of diagnostics.lua or any backend after main is updated. Also fixes the remote sniffer raising on an absent method and the Debug metrics crash when Stats members are missing.
0.0.67 | Remote sniffer no longer reads absent methods as raw indexes: a RemoteFunction has no FireServer and a RemoteEvent has no InvokeServer, so each method read is pcall-guarded and the absent one is skipped instead of raising and failing the whole backend load.
0.0.66 | Debug console metrics no longer crash when the executor does not expose Stats.FrameStats/Network: every optional Stats and Workspace read now resolves through FindFirstChild, so FPS/ping/titans degrade to no-data instead of raising.
0.0.65 | Every game backend now reports its own structure into the Debug tab: named instances, live feature state, watches and console commands, so a game update that breaks a dependency shows up as [FALHA] at the point of failure.
0.0.64 | Live Debug console: streaming log, live FPS/ping/memory/uptime metrics, feature state auto-refresh, warn/print/error hooks, remote sniffer and terminal commands in every game.
0.0.63 | Shared Debug tab: module health, game-structure probes, live feature state and a copyable diagnostic report in every game.
0.0.10 | One Auto Block switch, defense priority over manual M1, continuous threat renewal and input guard cleanup.
0.0.9 | Opponent streaming rebind, local death cleanup and paired counter input release.
0.0.8 | Predictive threat engine, facing validation, closing-speed checks, configurable counter timing, unknown-animation logger and expanded combat diagnostics
