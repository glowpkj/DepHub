0.1.01 | Shared UI (every game): sections now hug their content. A section's height is the measured content of its body, and since that measurement already includes the body's own padding the old size added an extra 24px of dead space under the last control -- the empty band that showed up at the bottom of a section. Removed. Also added real VStack/HStack grouping: related controls sit side by side on one line (a toggle next to the slider that drives it, the switches of one feature together) across Volleyball 4.2, Universal, Violence District, TSB, MM2, Noob Piece, AOT:R, Blood Strike, Steal An Egg, Restaurant Tycoon 3 and Blox Fruits, so tabs are shorter and less cluttered. New shell primitives AddHStack/AddVStack, exposed as Kit.Row/Kit.Stack, with tests.
0.1.00 | Shared UI (every game) + Debug: full English pass. Every player-visible string -- tab names, section titles, toggle/slider labels, paragraphs, notifications, status reads and the Debug console vocabulary ([FAIL], module/probe details, command replies) -- is now English (was Portuguese). Docs and code comments stay in Portuguese. Also the default open/close key is now N. The Debug tab, loader notes and backend diagnostics all read in English.
0.0.99 | Blood Strike: reorganised into the Visual category. The two sections (players + info) were the same finalidade, so they are now one ESP section; the game-named tab is gone.
0.0.98 | Blood Strike: the ESP tab now actually shows its controls. The shared shell's tab:CreateSection takes (title, column) and rejects any column other than Left/Right; the backend passed a summary string in the column slot, so every section failed inside its pcall and the tab came up empty. Same fix applied to Violence District and Steal An Egg.

0.0.79 | Steal An Egg (place 107778070777162): teleport ported from Blox Fruits -- a CFrame tween fly that glides the HumanoidRootPart to the target at a set fly speed, zeroing linear velocity and stripping collision during the move (noclip) while never anchoring the character. Targets are saved in game as waypoints (persisted to disk when the executor exposes file IO, otherwise kept in memory), because the map coordinates are not known ahead of time. Controls live in a fixed Teleport tab.

Controls live in a fixed Speed tab.

0.0.76 | Every game now gets a fixed Dashboard tab built by the loader itself, so the same home screen shows no matter which backend runs: the player greeting card (avatar, name, clock) plus the game/server card, and live performance metrics (framerate, latency, players, session). 0.0.75 | The shared UI theme was split into ten ordered modules under src/core/ui/theme/ (data, sub-tabs, constructor, theme-apply, notifications, window, extras, public-api, controls, lifecycle); the orchestrator loads them in the original section order and each adds its methods to the one Library table, so behaviour is unchanged while the 13k-line file is now maintainable in pieces.
0.0.74 | The real UI theme is now covered by an automated test: the suite loads the actual demon-theme.luau (not the stub the backend tests use), builds a window against a Roblox double, then creates a category, tab, section and controls and destroys it, so a theme regression fails the suite instead of only showing up in-game.
0.0.73 | The Debug tab and the print/warn log hooks are now opt-in and off by default, so the hub runs clean in every game; the collector and every backend probe keep running underneath.
